# Toikake - AI問いかけ生成

親が今読んでいるWebページ(記事/絵本/動画)に対して、ボタン1つで「子どもへの問いかけ例」をAIが5つ生成するChrome拡張機能です。対話型教育を求める親向けに、子どもの思考を深める質問を提案します。

## 機能

- **1クリック生成**: 開いているWebページの内容から、5パターンの質問(事実確認・気持ち・想像・比較・未来)を生成します。
- **年齢チューニング**: 子どもの年齢に合わせて、質問の文体や言葉遣いを自動調整します。
- **教科特化モード**: 国語、算数、理科、社会、道徳など、特定の教科の視点から問いかけを生成できます。
- **履歴とメモ**: 生成した質問の保存、お気に入り登録、子どもとの対話メモの記録が可能です。
- **選択範囲生成**: ページ内の特定のテキストを選択して問いかけを生成することもできます。
- **ダークモード**: サイドパネルとオプション画面はダークモードに対応しています。

## インストール方法 (開発中)

1. このリポジトリをクローンまたはダウンロードします。
2. Chromeで `chrome://extensions/` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、ダウンロードした `toikake` フォルダを選択します。

## 使い方

1. 拡張機能のオプション画面で、Gemini APIキーを設定します。
2. 対象となるWebページを開きます。
3. ツールバーの「Toikake」アイコンをクリックしてサイドパネルを開き、「問いかけを生成」ボタンをクリックします。
   - または、ページ内のテキストを選択して右クリックメニューから「Toikakeで問いかけ生成」を選択します。
4. 生成された5つの質問がサイドパネルに表示されます。

## 設定項目

オプション画面から以下の設定が可能です。

- Gemini APIキーの登録
- 子どもの年齢設定 (複数登録対応)
- 教科特化モードのデフォルト選択
